# IDs de artboard (ART-Pn-nn)

Cada tarefa do plano aponta para o artboard esperado. Os IDs são estáveis; o título do artboard no canvas traz o ID.

## Parte 1: avaliação do adulto (DES-12)

Fonte: PDF "Guilherme Machado de Oliveira avaliação" e planilha "18 anos acima" (aba av.antropométrica). Substituem os antigos `A-Avaliacao-Medidas`, `-Composicao`, `-Resumo` e `T-Avaliacao-Passos` (removidos).

| ID | Arquivo | Tela |
| --- | --- | --- |
| ART-P1-01 | `A-Pacientes-Escala` | Lista de pacientes para 100 ou 1000: busca, chips de filtro, fixados/recentes, índice A–Z |
| ART-P1-02 | `A-Paciente-Atalhos` | Ficha com atalhos "Nova avaliação" e "Ver gráficos" |
| ART-P1-03 | `A-Avaliacao-Secoes` | Hub das 7 seções da planilha com status |
| ART-P1-04 | `A-Avaliacao-Cadastro` | Cadastro: sexo, atividade, objetivo, pesos, punho, compleição, diâmetros |
| ART-P1-05 | `A-Avaliacao-PesoEstatura` | Peso, IMC, peso teórico mín/máx, siglas, risco, gráfico de peso |
| ART-P1-06 | `A-Avaliacao-Perimetros` | 9 perímetros, classificação da cintura, gráfico |
| ART-P1-07 | `A-Avaliacao-Dobras` | 7 dobras, somatório, gráfico |
| ART-P1-08 | `A-Avaliacao-Composicao-Tabela` | Composição completa (residual, % desejado), gráfico gordo × magro |
| ART-P1-09 | `A-Avaliacao-Graficos` | Resultado: gráficos de Peso, Perímetros e Dobras |
| ART-P1-10 | `A-Avaliacao-Graficos-2` | Resultado: Composição e texto-resumo, PDF e compartilhar |
| ART-P1-11 | `P-Resultados-Graficos` | Paciente: Meus resultados com os gráficos |
| ART-P1-12 | `T-Pacientes-Avaliacao` | Tablet: lista e resultado lado a lado |
