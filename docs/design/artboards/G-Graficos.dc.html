Regras

Valem para todo gráfico
  • Sempre rótulo e valor em texto; cor nunca é a única pista.
  • Séries na ordem: verde, azul, âmbar, roxo, turquesa, cinza (âmbar #B07A00, roxo #7B5BA6, turquesa #2A7F7D, cinza #66736A: todas com 3:1 ou mais sobre branco).
  • Laranja só para alerta, nunca como série.
  • “Ver como tabela” em todo gráfico de dados.
  • Fatias separadas por 2 dp de espaço.
  • Entrada animada em 600 ms (sem animar se o sistema reduz movimento).
